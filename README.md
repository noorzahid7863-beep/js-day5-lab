# Modern JavaScript Concepts — Day 5 Lab

This repository contains practical implementations and code examples for **Day 5** of the **Full-Stack Engineering Bootcamp**.

## 📚 Topics Covered

1. **Higher-Order Functions (HOFs)**
   - Array iteration and processing using `map()`, `filter()`, and `reduce()`.
   - Searching and verification using `find()`, `some()`, and `every()`.

2. **Asynchronous JavaScript & Event Loop**
   - Understanding Call Stack, Microtask Queue, and Task Queue.
   - Custom Promise simulation with asynchronous delay handling.
   - `async / await` syntax with robust `try...catch` block management.

3. **Fetch API & Working with JSON**
   - Executing HTTP requests using native `fetch()`.
   - Parsing JSON responses and handling HTTP status errors (`response.ok`).
